# 공개판 보안·개인정보 점검

[English](SECURITY_REVIEW.md) · [한국어 안내](../README.ko.md)

공개 소스·테스트·문서는 가상 주소·예약자·장비·캘린더 ID를 사용합니다. 인증 정보·운영 로그·내보내기·백업은 제외합니다.

## 적용한 보호

- 시트에 쓰는 외부 텍스트의 수식 시작 문자와 이메일 HTML의 동적 텍스트를 이스케이프합니다.
- 통계·캘린더 그룹 객체의 프로토타입을 제거해 특수 키 충돌을 방지합니다.
- 개인 이메일은 한 개만 허용하고 잘못된 주소는 관리자에게 안내하며, 메일 헤더의 줄바꿈을 차단합니다.
- `testFooterMail`의 `TEST_GROUP_EMAIL`은 한 개의 주소만 허용하고 실제 그룹 주소는 거부합니다.
- 그룹 주소를 검증하고 수신 거부·지난 메일 링크를 인코딩하며, 표시할 그룹 이름을 이스케이프합니다.
- 애플리케이션 로그의 개인정보는 `LOG_PERSONAL_DETAILS: true`일 때만 출력합니다.
- 처리 실패 시 이전 동기화 토큰과 마지막 성공 시각을 유지해 다음 실행에 재시도합니다. 전체 읽기가 성공하고 일정이 없어도 취소를 대조합니다.

## 권한

매니페스트는 `https://www.googleapis.com/auth/` 아래 네 범위를 사용합니다: `calendar.readonly`, `spreadsheets.currentonly`, `script.send_mail`, `script.scriptapp`(Calendar 읽기, 현재 스프레드시트, 메일 발송, 트리거 관리).

## 검증

`npm test`를 실행한 뒤 `SIM_ORDER=alpha`로 반복합니다. 규칙·시뮬레이션·수식/HTML 이스케이프·주소와 헤더 검증·바닥글 수신자와 링크·로그·동기화 재시도·공개 파일의 개인정보를 검사합니다.

## 설치 후 확인

실제 운영에서는 예약 정보를 저장하고 메일로 보냅니다. 시트 접근과 그룹·지난 메일 열람 권한을 제한하고 시험 그룹도 관리하세요. `testFooterMail`에는 현재 예약이 포함됩니다. 상세 로그나 플랫폼 예외 로그에도 운영 데이터가 남을 수 있습니다.

테스트는 Google 서비스를 모의합니다. 설치 후 권한·메일 전달·바닥글 표시를 확인하세요. Google Groups와 메일 앱이 바닥글 HTML을 바꿀 수 있습니다.
